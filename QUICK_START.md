# Quick Start Guide

## 🚀 Get Started in 3 Steps

### Step 1: Open the Project
```bash
open Englisch-Vokabel-Trainer.xcodeproj
```

### Step 2: Select a Device
In Xcode toolbar, click the device selector and choose:
- **iPhone 15 Pro** (Simulator) - Recommended for testing
- Or any connected iPhone

### Step 3: Build & Run
Press **⌘ + R** or click the Play button ▶

**That's it!** The app will launch with 90+ vocabulary items ready to learn.

---

## 📱 Using the App

### Learning Tab (Default)
1. **View English vocabulary** - with optional syllable separation
2. **Click "Übersetzung anzeigen"** - to see German translation
3. **Click "✔ Gewusst"** - if you knew the word (marks as learned)
4. **Click "Nächste Vokabel →"** - to continue learning

### Settings Tab
- **Toggle Dark Mode** - Switch between dark/light theme
- **Toggle Silbentrennung** - Show/hide syllable separation
- **Toggle Zufallsmodus** - Shuffle unlearned vocabulary
- **Vokabeln hinzufügen** - Add your own vocabulary
- **Lernstatus zurücksetzen** - Clear all learned flags
- **View Statistics** - See your progress

---

## 🎨 Key Features

### Syllable Separation (LRS Support)
When enabled, vocabulary appears like this:
- **ba-na-na** (blue-red-purple colors)
- **to fall a-sleep** (per-word separation)

### Shuffle Mode
- Focuses on **unlearned vocabulary only**
- Randomizes order each cycle
- Automatically restarts when complete

### Progress Tracking
- See **X / Y** learned count at top
- View **percentage** in Settings
- **Checkmarks** show learned items

---

## 📝 Adding Your Own Vocabulary

1. Go to **Settings** tab
2. Tap **"Vokabeln hinzufügen"**
3. Fill in the form:
   - **Englisch**: The English word/phrase
   - **Deutsch**: The German translation
   - **Silbentrennung**: Use `-` for syllables, spaces for words
4. Examples:
   - `ba-na-na` (single word)
   - `to fall a-sleep` (phrase)
   - `he has a lot to learn` (sentence)

---

## 🎯 Tips for Best Results

### For Children with Dyslexia
- ✅ **Enable syllable separation** (Silbentrennung)
- ✅ **Use dark mode** (easier on eyes)
- ✅ **Enable shuffle mode** (variety helps memory)
- ✅ **Learn in short sessions** (10-15 minutes)
- ✅ **Review regularly** (reset and retry)

### For Parents/Teachers
- 📊 **Check statistics** regularly
- 📝 **Add custom vocabulary** from school
- 🔄 **Reset learning status** for review
- 🎨 **Keep syllables enabled** for spelling support

## 🔧 Troubleshooting

### App won't build?
1. Clean build folder: **⌘ + Shift + K**
2. Rebuild: **⌘ + B**

### No vocabulary showing?
- Check that `vocab_seed.json` is in the project
- Look for errors in Xcode console

### Dark mode not working?
- Check Settings tab → Dark Mode toggle
- Restart the app

## 🎓 Educational Approach

This app uses **simplified didactic phonological separation** based on:
- grammatikguru.de principles
- Adapted for children with dyslexia (LRS)
- Color-coded syllables (blue, red, purple)
- Visual learning support

### Why Syllable Separation?
Children with dyslexia often **know the word but write it phonetically**. Syllable separation helps them:
- See word structure clearly
- Remember correct spelling
- Build confidence in writing
